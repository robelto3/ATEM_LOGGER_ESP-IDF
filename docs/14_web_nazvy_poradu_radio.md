# Web – názvy pořadů a výběr aktivního pořadu

Na stránce `Názvy pořadů` jsou jednotlivé řádky formuláře uspořádané takto:

```text
Název pořadu 1   [ textové pole ]   (•) aktivní
Název pořadu 2   [ textové pole ]   ( ) aktivní
```

Radio box pro výběr aktivního pořadu je umístěný vpravo za textovým polem.

Radio puntík používá CSS:

```css
accent-color: crimson;
```

Díky tomu je vybraný puntík barevně sjednocený s crimson zvýrazněním aktivního pořadu na Home stránce.


## Aktivní řádek

V navazujícím kroku je text `aktivní` u aktuálně vybraného řádku zvýrazněn barvou `crimson`.
