# Web: barevné odlišení aktivního filtru souborů

Ve výpisu souborů jsou tři režimy:

- soubory se střihy
- střihy = 0
- všechny soubory

Aktivní režim je zvýrazněný třídou:

```css
.btn-active
```

Použité zvýraznění:

```css
.btn-active {
    background: #3a101a;
    border-color: crimson;
    color: #fff;
    font-weight: bold;
}
```

Režim se stále pamatuje pouze v RAM do resetu.
