# Sjednocené tlačítko RTC Synchro

Na Home stránce má `RTC Synchro` stejný vizuální styl jako ostatní tlačítka.

Důvod: `RTC Synchro` je HTML `button` ve formuláři, zatímco ostatní položky jsou odkazy `a.btn`.
Pro sjednocení vzhledu je základní styl `.btn` společný a `button.btn` má odstraněný výchozí systémový vzhled přes `appearance:none`.
