# Web Home – stavové hodnoty pod sebou

Home stránka má stavové hodnoty rozdělené do samostatných řádků kvůli lepší čitelnosti při větším písmu.

Nové rozložení:

```text
ESP IP: 10.0.0.9
ATEM IP: 10.0.0.10

ATEM: OK/---
LTC: OK/---

PGM: N
PVW: N
TC: HH:MM:SS:FF
```

Živá aktualizace přes `/api/state` zůstává zachovaná.
