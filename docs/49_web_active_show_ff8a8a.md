# Web – aktivní pořad na Home barvou #ff8a8a

Na Home stránce je název aktivního pořadu zvýrazněný světle červenou barvou:

```css
.active-show {
    color: #ff8a8a;
    font-weight: bold;
}
```

Změna je pouze kosmetická. Funkce výběru pořadu, živý Home stav i vytváření EDL souborů zůstávají beze změny.
