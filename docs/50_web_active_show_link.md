# Aktivní pořad jako odkaz na Názvy pořadů

Na stránce Home je název aktivního pořadu klikací.

Řádek:

```text
Aktivní pořad: Název pořadu
```

Nově vede kliknutí na název pořadu na stránku:

```text
/shows
```

Tedy na nastavení názvů pořadů.

Barva aktivního pořadu zůstává:

```css
#ff8a8a
```

Funkčně se nic dalšího nemění.
