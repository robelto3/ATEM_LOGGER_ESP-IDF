# Web: zarovnání sloupců Zobrazit a Stáhnout

Ve výpisu souborů jsou sloupce `Zobrazit` a `Stáhnout` zarovnané na střed.

Platí pro:

- hlavičky tabulky
- odkazy v jednotlivých řádcích

Použité CSS třídy:

```css
.view-cell {
    text-align: center;
    white-space: nowrap;
}

.download-cell {
    text-align: center;
    white-space: nowrap;
}
```

Funkce webu se tím nemění, jde pouze o kosmetické doladění tabulky souborů.
