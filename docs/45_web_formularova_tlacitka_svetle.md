# Formulářová tlačítka se světlým písmem

Úprava webového CSS pro formulářová tlačítka.

Tlačítka typu `button.btn`, například:

- Uložit názvy pořadů
- Uložit nastavení

mají nově světlé písmo, aby byla dobře čitelná na tmavém pozadí.

RTC Synchro zůstává speciálně zvýrazněné modře přes třídu `rtc-sync-btn`.
