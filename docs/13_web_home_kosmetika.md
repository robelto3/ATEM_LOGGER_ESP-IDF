# Web Home kosmetika

## Nadpis Home

Na hlavní webové stránce je stavová karta označená jako:

```text
Home
```

Stejný text se používá i v navigačních tlačítkách pro návrat na hlavní stránku.

## Aktivní pořad

Aktivní název pořadu je na Home stránce zvýrazněný barvou:

```css
#ff8a8a
```

Díky tomu je při kontrole před záznamem hned vidět, jaký pořad bude zapsaný do `TITLE:` v novém EDL souboru.
